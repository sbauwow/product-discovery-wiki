# Blue Ocean Strategy

> Source: W. Chan Kim & Renée Mauborgne, *Blue Ocean Strategy* (2005). Strategic differentiation framework: don't compete in **red oceans** (existing markets, competing on the same dimensions); create **blue oceans** (uncontested market space).

## Red ocean vs blue ocean

```
RED OCEAN                          BLUE OCEAN
─────────────                      ──────────────
Compete in existing markets        Create uncontested markets
Beat the competition               Make competition irrelevant
Exploit existing demand            Create and capture new demand
Make value-cost tradeoff           Break the value-cost tradeoff
Compete on incremental features    Compete on entire offering shape
Margins compress over time         Margins sustain (no direct competitor)
```

Red ocean = bloody from competition. Blue ocean = uncontested water. The book argues most strategy frameworks (Porter, etc.) optimize red-ocean play; the highest-value moves create blue oceans.

## The four-action / ERRC framework

The mechanic for creating blue oceans. Look at the existing industry's "factors of competition" and ask:

```
                     INDUSTRY'S
                  FACTORS OF COMPETITION
                          │
            ┌─────────────┼─────────────┐
            │             │             │
        ELIMINATE        RAISE
        which factors    which factors
        the industry     should be
        takes for        raised well
        granted should   above the
        be eliminated?   industry standard?
            │             │
            ├─────────────┼─────────────┤
            │             │             │
        REDUCE           CREATE
        which factors    which factors
        should be        should be
        reduced well     created that
        below the        the industry
        industry         has never
        standard?        offered?
            │             │
            └─────────────┴─────────────┘
                     NEW VALUE CURVE
                  (your blue ocean)
```

Most red-ocean strategy is "Raise" or "Reduce" — incremental delta on an existing dimension. Blue-ocean strategy emphasizes **Eliminate** (take away things the industry assumes mandatory) and **Create** (add things the industry doesn't offer).

## Worked examples

### Cirque du Soleil
Existing industry (circus) factors of competition: animals, star performers, multiple show rings, concession sales.

```
ELIMINATE: animals (cost, controversy, logistics)
ELIMINATE: star performers (cost)
ELIMINATE: multiple rings (logistics)

REDUCE: thrills/danger (high cost, lower differentiator)

RAISE: unique venue, theme

CREATE: artistic music + dance (theatre crossover)
CREATE: refined environment (target adults, not just kids)
CREATE: theme + storyline (each show is unique)
```

Result: combined circus + theatre into a new category. Charged 10x typical circus prices. No direct competitors.

### Yellow Tail Wines
Existing wine industry factors: prestige terminology, aging, vineyard prestige, wine complexity.

```
ELIMINATE: enology terminology (intimidating)
ELIMINATE: aging qualities

REDUCE: complexity, range of varietals

RAISE: ease of selection, fun vibe

CREATE: easy-drinking wine
CREATE: fruit characteristics
CREATE: simple appeal for casual drinkers
```

Targeted non-wine-drinkers (a *new market*, like [new-market disruption](disruption-theory.md)). Became the fastest-growing wine brand in US history.

### Nintendo Wii
Existing console industry: graphics realism, processing power, hardcore-gamer features.

```
ELIMINATE: high-end graphics push, complex controllers

REDUCE: processing horsepower

RAISE: family-friendly content, motion physical interaction

CREATE: motion-controlled gameplay
CREATE: party/family game category
```

Sold to non-gamers (parents, families, elderly). Outsold PS3 + Xbox 360 combined for years.

## The strategy canvas

Blue Ocean's central visualization:

```
Performance level (high)
        │
   ●────●           ─── existing industry leaders
        ●           
        ●─────●     
              ●     
        │     │     
   ●────●─────●──── NEW PLAYER — your blue ocean curve
              │     (different shape, not just better)
              │
              ●
        │     │
        ─────────────────────────────────→ factors of competition
        F1   F2   F3   F4   F5   F6
```

Plot competitors and yourself across all factors. Your curve should look *visually different* from competitors — not just higher or lower on the same dimensions, but *shaped differently*. Different shape = different strategy.

## Connection to other concepts

### vs Disruption theory
Both create non-direct competition with incumbents.
- [Disruption](disruption-theory.md): start in low-end / nonconsumers; inferior on existing metrics; improve over time
- Blue ocean: start with a new value curve; *different* on metrics, not inferior

Many disruptive products are also blue-ocean. The frameworks overlap but emphasize different mechanics.

### vs JTBD
[JTBD](jobs-to-be-done.md) asks "what job is the customer trying to do?" Blue ocean asks "what value curve could we offer?" JTBD is upstream; blue ocean is downstream.

### vs Wardley Mapping
[Wardley](wardley-mapping.md) maps existing components by visibility × evolution. Blue ocean asks how to *change the user need* the components serve, by changing what gets eliminated/reduced/raised/created.

## Critiques

- **Survivor bias** — book uses post-hoc examples (Cirque, Wii). Doesn't address all the failed blue-ocean attempts.
- **"Create new demand" is harder than the book suggests** — most "blue oceans" turn into red oceans within 5-10 years as competitors copy
- **Doesn't address execution** — strategy can be blue, but execution against the strategy is still hard
- **ERRC over-prescriptive** — the framework can produce mechanical lists rather than insightful strategy
- **Hard to know if you're in blue water until later** — many "uncontested markets" are uncontested because nobody wants them

## When blue-ocean framing helps

✅ Stuck competing in red ocean (margin compression, feature parity)
✅ Stagnant industry primed for differentiation
✅ Large company with resources to create category
✅ Strategy off-site / planning
✅ Pairing with [JTBD](jobs-to-be-done.md) discovery work

## When less useful

❌ Pre-PMF startups (focus on JTBD + PMF first)
❌ Tactical product decisions
❌ Industries where regulation forbids elimination/reduction (healthcare, finance)
❌ Network-effect industries where dominant player owns existing dimensions

## Common failure modes

- **Eliminate / reduce too much** — strip the product to where customers no longer want it
- **Create / raise without eliminating** — adds features without removing cost; not a blue ocean, just over-built
- **Misdiagnose competitive factors** — choose factors that aren't actually what customers value; ERRC is wasted on the wrong axes
- **Treating ERRC as a checklist** — running the framework mechanically without strategic insight
- **No customer validation** — designed a beautiful new value curve nobody actually wants
- **Not defending the blue ocean** — once successful, competitors copy; strategy degrades to red over time without continued differentiation
